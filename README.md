# 📊 Risk Analysis Commodities

📝 This notebook presents a study on the correlation between financial assets using different statistical methods, with a special focus on the **DCC-GARCH** model. The script downloads historical data, calculates logarithmic returns, and then applies three distinct approaches to estimate the correlation over time:

*   🔄 **Rolling Correlation:** A classic method that computes the Pearson correlation using a uniform, fixed rolling time window.
*   📉 **EWMA Correlation:** Computes the Exponentially Weighted Moving Average correlation (RiskMetrics), applying a decay factor to give more importance to recent observations.
*   🔬 **DCC-GARCH (Dynamic Conditional Correlation):** An advanced econometric model that dynamically estimates conditional correlation.
*   This robust implementation includes a constant mean correction (drift) and strict parameter bounds to prevent the model from collapsing into a static straight line.

📊 The visual dashboard generated by the code compares the normalized prices of the assets (base 100) and displays the evolution of their dynamic correlation across the selected methods (Rolling, EWMA, and DCC-GARCH). 
💡This provides valuable insights into the volatility and the changing relationships between the analyzed commodities over time.
